# Horizon Video Screen (`video_screen`)

Native trait-мод для [Horizon](https://github.com/normikq/horizon) (ветка `mpv-support`), добавляющий воспроизведение видео на поверхности в игровом мире через `libmpv`.

---

## 🎮 Возможности

- Воспроизведение локальных видеофайлов на виртуальном экране прямо в мире Minecraft.
- **Сохранение экранов по идентификатору (ID)**: сохраняйте точки размещения и размеры экранов в `video_screens.json` и запускайте видео командой `/video play <id> <файл>`.
- **Интерактивный 3D-редактор с красной сеткой**:
  - При создании (`/video create <id>`) или редактировании (`/video edit <id>`) отображается яркая красная контурная рамка и внутренняя сетка 4×4.
  - 4 угловых маркера (Corner handles) для масштабирования с **сохранением заданного соотношения сторон**.
  - 4 рамных маркера (Edge handles) для независимой регулировки ширины и высоты.
  - Интерактивное перетягивание мышью прямо из открытого игрового чата (клавиша `T` или `/`).
- **Кликабельные кнопки в чате**:
  - `[💾 Сохранить]` — сохранение текущих координат и геометрии экрана;
  - `[16:9]`, `[4:3]`, `[21:9]`, `[1:1]` — быстрое переключение пропорций экрана;
  - `[Auto]` — автоматическое определение соотношения сторон из видеопотока mpv;
  - `[❌ Закрыть]` — выход из режима редактирования.
- Динамический вывод кадров в текстурный атлас игры без отдельного окна.
- Автономный вывод звука силами mpv.

### Игровые команды

#### 🖥️ Управление экранами и визуальный редактор
| Команда | Описание |
|---|---|
| `/video create <id>` | Создаёт новый экран с заданным ID перед игроком и открывает интерактивный редактор |
| `/video edit <id>` | Открывает визуальный редактор для существующего сохраненного экрана |
| `/video save [id]` | Сохраняет текущую позицию и габариты экрана в `video_screens.json` |
| `/video list` | Выводит список сохраненных экранов с кликабельными кнопками `[✏ Редакт]` и `[🗑 Удалить]` |
| `/video play <id> <путь_к_файлу>` | Запускает воспроизведение видео на сохраненном экране `<id>` |
| `/video remove <id>` | Удаляет сохраненный экран из реестра и диска |
| `/video cancel` | Закрывает визуальный редактор и скрывает красную сетку |

#### 📐 Геометрия и пропорции
| Команда | Описание |
|---|---|
| `/video size <диагональ>` | Настройка размера экрана по диагонали в блоках (от 0.5 до 50.0) |
| `/video grow [шаг]` | Увеличивает диагональ экрана на `шаг` блоков (по умолчанию +0.5) |
| `/video shrink [шаг]` | Уменьшает диагональ экрана на `шаг` блоков (по умолчанию -0.5) |
| `/video distance <блоки>` | Настройка расстояния экрана перед игроком (от 1.0 до 100.0) |
| `/video aspect <соотношение>` | Выбор соотношения сторон (`auto`, `16:9`, `4:3`, `21:9`, `1:1`, `W:H`) |
| `/video reset` | Сброс размеров (4.0×2.25) и расстояния (4.0 блока) к значениям по умолчанию |

#### ⏯️ Воспроизведение
| Команда | Описание |
|---|---|
| `/video open <путь_к_файлу>` | Открывает локальный видеофайл на быстром экране перед игроком |
| `/video pause` | Ставит видео на паузу |
| `/video play` | Возобновляет воспроизведение |
| `/video seek <секунды>` | Перемотка на указанную позицию |
| `/video volume <0-100>` | Регулировка громкости звука mpv |
| `/video close` | Закрывает видео и скрывает экран |
| `/video info` | Выводит в лог позицию, длительность и статистику рендера |

Переменная окружения `HORIZON_VIDEO_DEMO=<путь>` позволяет автоматически запустить видео при загрузке мира.

## ⚙️ Установка и запуск

### 1. Требования
- Сборка Horizon с поддержкой сторонних библиотек: [normikq/horizon (ветка mpv-support)](https://github.com/normikq/horizon/tree/mpv-support).
- Библиотека `libmpv-2.dll` (Windows x64) с SHA-256, указанным в `native-libraries.toml`:
  ```text
  0fc3d4a64453fc65b801a687cede8196899788a81a4cd082a9ea477fc418b10f
  ```

### 2. Размещение библиотеки
Лаунчер Horizon по соображениям безопасности и лицензионной чистоты не загружает сторонние DLL из сети. Библиотека берётся:
1. Либо из папки `native/libraries/libmpv-2.dll` в директории лаунчера Horizon;
2. Либо из папки `data/libmpv-2.dll` внутри бандла этого мода.

При сборке лаунчер проверяет SHA-256 хэш файла и копирует его в папку версии игры.

### 3. Сборка через Horizon Launcher
```sh
horizon-launcher native-build /путь/к/horizon-video --instance <ваша_инстанция> --trust-native-code
```

Или упакуйте мод в бандл `.hnmod` для установки через интерфейс лаунчера.
